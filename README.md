# 环沪 40 万内二手房采集、清洗与选房站

从房天下（搜房网）环沪城市二手房频道采集总价 ≤40 万的房源，落库 SQLite，做公寓/小产权/农村/疑似虚假过滤，导出 Excel，并提供一个移动端优先的查询网站（已配置公网隧道）。

数据快照：2026-10-26，共 **8,111** 条 40 万内房源；清洗后 **4,574** 条相对可信的住宅。

过滤明细：公寓/商住 **2,187**、重复挂牌 **1,108**、农村/偏远 **505**、挂牌超 2 年 **310**、疑似虚假 **54**、小产权 **10**。

各城市清洗后数量：南通 1,567、湖州 1,286、嘉兴 1,033、昆山 364、常熟 109、上海 79、启东 63、海门 58、苏州 12、太仓 3。

贷款标注（精选 4,574 套内）：可商贷 **4,309**、可公积金 **276**、公积金待核（房龄未标注）**4,280**、商贷需核实 **262**、不可按揭 **3**。

## 覆盖城市

上海、昆山、太仓、苏州、常熟、南通、启东、海门、嘉兴、湖州。

## 过滤规则

- **公寓/商住**：房屋用途或标题/描述含公寓、SOHO、LOFT、写字楼、商铺、商住等
- **小产权**：含小产权、农民房、自建房、宅基地、村委、集资房；以及低价大面积异常样本
- **农村/偏远**：含乡/农场/自然村/农村/自建房等，或“XX村”（“新村”除外），或距所属城市中心过远
- **疑似虚假**：单价与总价明显不符、单价 <1500 元/㎡、面积异常，或单价低于区县中位 45%、低于小区中位 52%
- **重复挂牌**：同城市 + 同小区 + 同面积 + 同总价，多中介重复挂牌只保留一条
- **挂牌超 2 年**：默认不进入精选

被过滤房源仍可在网站「筛选 → 查看被过滤的房源」中查看，并附过滤原因。

## 贷款标注

每套房源都会给出「商贷 / 公积金」两行结论，网站卡片上有标签，详情里有首付与可贷年限估算：

- **可商贷**：住宅性质、房龄 ≤35 年（或房龄未标注）、面积 ≥30㎡，且未出现“全款/无产证”等限制
- **可公积金**：在可商贷基础上，房龄已知且 ≤30 年；房龄未标注时标为「公积金待核」
- **需核实**：房龄 36-40 年、面积 <30㎡、经济适用房/安置房/房改房等特殊产权
- **不可按揭**：小产权/无产权、挂牌写明必须全款
- 公寓/商办：只能走商业贷款（首付约 5 成、最长 10 年），不可公积金
- 首付按首套约 2 成估算，公积金还需连续缴存、账户余额与当地额度上限，最终以银行评估与产权核验为准

房龄来源优先级：详情页“建筑年代” → 同小区已知建成年份中位数 → 标题中的年份；三者都没有时标为“房龄未标注”。

## 目录

```
.
├── crawl_around.py        # 环沪多城市采集器（列表 + 详情）
├── analyze.py             # 清洗、虚假房源识别、统计、导出 Excel
├── lt_client.py           # 公网隧道客户端（适配只允许 HTTP 代理出网的环境）
├── fang.db                # 原嘉兴全量库（历史数据，作为嘉兴补充）
├── sh_around.db           # 环沪 40 万内主库
├── analysis.json          # 网站分析报告数据
├── 环沪40万二手房分析.xlsx  # 分析 Excel（精选/全部/已过滤/城市/区县/小区/规则）
└── web/
    ├── app.py             # Flask 后端
    └── templates/
        └── index.html     # 移动端单页
```

## 重新采集

```bash
python crawl_around.py --list-only --import-jx   # 列表页 + 嘉兴历史库补充
python crawl_around.py --detail-only --workers 8 # 详情补全（用途/电梯/坐标/挂牌时间）
python analyze.py                                # 清洗 + 统计 + Excel
```

采集器会自动写入房天下详情页校验所需的 `otherid` Cookie，避免频繁触发滑块验证；但高频访问仍可能被临时限流。

## 启动网站

```bash
pip install flask requests pandas openpyxl
cd web
PORT=8000 python app.py
```

- 本机：`http://127.0.0.1:8000`
- 局域网：`http://<本机IP>:8000`

公网访问（当前会话）：

```bash
python lt_client.py --local-port 8000
```

会生成 `https://xxx.loca.lt` 公网地址；首次打开需在 loca.lt 提示页输入页面显示的验证 IP。免费隧道地址在客户端重启后会变化。

## 数据说明与局限

- 房天下挂牌价不等于成交价，实际可议价
- 详情页受平台限流，部分房源未补全“房屋用途/电梯/坐标”，这部分主要依据列表字段与标题规则判断
- 区县/板块字段对部分房源缺失，网站按城市筛选不受影响
- 虚假房源无法 100% 判定，本站按异常低价、单价与总价不符、非住宅、多中介重复等信号做“疑似”过滤，最终以产权核验和实地看房为准
- 数据仅用于个人购房决策参考，请勿用于商业用途或大规模再分发
